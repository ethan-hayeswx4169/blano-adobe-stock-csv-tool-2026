## Overview

Blano Adobe Stock CSV Generator is a browser-based utility for turning image files into Adobe Stock-ready CSV data. It combines image inspection with AI-assisted metadata creation, giving creators a structured way to prepare stock submissions without leaving the web workflow.

The application runs as a Vercel web app and is intended for individuals and production teams working with image collections. Sequential batch analysis helps organize larger sets, while browser-side resizing keeps image preparation within the same upload and review process.

## Workflow

A standard processing session looks like this:

1. Load the application in a browser.
2. Select and add the images to be prepared.
3. Allow the app to analyze each image in order.
4. Inspect and, if necessary, edit the suggested titles and keywords.
5. Resize the images in the browser when required.
6. Export the completed Adobe Stock CSV.

When handling many files, use smaller groups. This keeps the sequential metadata process manageable and makes the results easier to check before the final export.
